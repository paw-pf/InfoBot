# POS Report Telegram Bot

Telegram-бот для автоматического распознавания скриншотов кассового ПО и сохранения данных в Google Таблицы.

## Возможности

- 📸 **Распознавание скриншотов** — EasyOCR с 4-проходной предобработкой
- 📊 **Умный парсинг** — корректная обработка OCR-ошибок и смешанных шрифтов
- 📝 **Google Sheets** — автоматическое заполнение таблицы с расчётными полями
- 🔄 **Дублирование отчётов** — отправка в личные сообщения + рабочий чат
- 🌙 **Авто-определение смены** — День/Ночь по времени
- 🐳 **Docker** — готовый контейнер для развёртывания

## Быстрый старт

### 1. Создание Telegram-бота

1. Откройте `@BotFather` в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте токен бота

### 2. Настройка Google Sheets

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте проект → включите **Google Sheets API** и **Google Drive API**
3. Создайте **Service Account**:
   - Credentials → Create Credentials → Service Account
   - Заполните данные → Done
4. Сгенерируйте JSON-ключ:
   - Keys → Add Key → Create new key → JSON
   - Сохраните как `credentials.json` в корне проекта
5. Создайте Google Таблицу
6. Откройте доступ для service account (email из credentials.json):
   - Share → Добавьте email → Editor permissions
7. Скопируйте ID таблицы из URL:
   - `https://docs.google.com/spreadsheets/d/SHEET_ID/edit`

### 3. Получение ID рабочего чата (опционально)

Чтобы отчёты дублировались в группу:

1. Добавьте `@userinfobot` в свою группу
2. Перешлите любое сообщение из группы этому боту
3. Скопируйте ID (отрицательное число, например `-1001234567890`)

### 4. Настройка окружения

```bash
# Скопируйте пример
cp .env.example .env

# Заполните значения в .env:
TELEGRAM_BOT_TOKEN=your_token_here
GOOGLE_SHEET_ID=your_sheet_id_here
REPORT_CHAT_ID=-1001234567890  # опционально
ALLOWED_USERS=123456789       # опционально, ID пользователей
```

### 5. Запуск

#### Локально

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python main.py
```

#### Docker (рекомендуется)

```bash
# Сборка и запуск
docker-compose up -d --build

# Просмотр логов
docker-compose logs -f

# Остановка
docker-compose down
```

## Использование

### Рабочий процесс

1. **Пользователь** открывает бота в личных сообщениях
2. Отправляет `/start Имя Дата` (или просто `/start`)
3. Отправляет скриншот из кассового ПО
4. Бот показывает отчёт в личке
5. **Если `REPORT_CHAT_ID` настроен** — отчёт дублируется в рабочий чат
6. Данные автоматически сохраняются в Google Таблицу

## Формат таблицы

Бот заполняет таблицу со следующими колонками:

| Колонка | Источник | Пример |
|---------|----------|--------|
| Дата | из команды | 28.03.2026 |
| Смена | авто-определение | День/Ночь |
| Администратор | из команды | Диана |
| Z-отчет | total | `31 905,00` |
| Игровое время + PS | game_time | `р.24 637` |
| Кальян | services | `1 800,00` |
| Бар | bar | `4 990,00` |
| Нал | cash | `2 245,00` |
| СБП+БЕЗНАЛ | sbp + cashless | `р.31 507,00` |
| СБП | sbp | `0,00` |
| Эквайринг | acquiring | `10 055,00` |
| Равно? | (оставляется пустым) | |
| ЭКВАЙРИНГ! в банк | acquiring - 2.5% | `9 803,63` |
| % экв | acquiring/total×100 | `383,50` |
| % сбп | sbp/total×100 | `113,17` |
| Расход | cash_expense | `0,00` |
| Возврат безнал | return_cashless | `0,00` |
| Возврат нал | return_cash | `0,00` |
| Инкассация | envelope | `0,00` |
| Примечание | (оставляется пустым) | |

**Форматирование:**
- Разделитель тысяч: пробел (`31 905,00`)
- Десятичный разделитель: запятая
- Игровое время: префикс `р.`
- СБП+БЕЗНАЛ: префикс `р.`

## Технология распознавания

### EasyOCR + 4-проходная предобработка

1. **Pass 0** — оригинал × 4 (upscale для лучшей точности)
2. **Pass 1** — повышенный контраст и яркость (для тёмного фона)
3. **Pass 2** — оттенки серого + бинаризация (для жёлтых строк)
4. **Pass 3** — инвертирование цветов (для светлого текста)

### Умная обработка ошибок OCR

- Поиск наибольшего числа среди всех вариантов распознавания
- Коррекция потерянных цифр через cross-reference (cash ↔ cash_remainder)
- Обработка смешанных кириллическо-латинских символов
- Fallback-паттерны для каждого поля

## Решение проблем

### Бот не отправляет отчёты в чат

- Проверьте `REPORT_CHAT_ID` в `.env`
- Убедитесь, что бот добавлен в чат
- Для супергрупп используйте полный ID с префиксом `-100`
- Проверьте права бота в чате (администратор с правом отправки)

### Google Sheets ошибки

- `credentials.json` должен быть в корне проекта
- Таблица должна быть открыта для service account
- Проверьте правильность `GOOGLE_SHEET_ID`
