# 🚀 Быстрая настройка бота для отчетов из кассового ПО

Пошаговая инструкция для запуска Telegram бота с EasyOCR и Google Sheets.

## 📋 Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: `Отчеты из кассы`)
   - Введите username бота (должен заканчиваться на `bot`)
4. **Скопируйте токен бота** (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### ⚙️ Настройка приватности (важно!)

1. В BotFather отправьте `/mybots`
2. Выберите вашего бота
3. **Bot Settings** → **Group Privacy** → **Turn off**
4. Это позволит боту читать сообщения в группах

## 📊 Шаг 2: Настройка Google Таблицы

### 2.1. Создание сервисного аккаунта Google

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите API:
   - **"APIs & Services"** → **"Library"**
   - Включите **"Google Sheets API"** и **"Google Drive API"**

4. Создайте сервисный аккаунт:
   - **"APIs & Services"** → **"Credentials"**
   - **"Create Credentials"** → **"Service Account"**
   - Заполните имя → **"Done"**

5. Создайте ключ:
   - Нажмите на сервисный аккаунт → вкладка **"Keys"**
   - **"Add Key"** → **"Create new key"** → формат **JSON**
   - Скачайте файл

6. Переименуйте в `credentials.json` и поместите в папку проекта

### 2.2. Создание Google Таблицы

1. Создайте таблицу: https://sheets.new
2. **Скопируйте ID из URL:**
   ```
   https://docs.google.com/spreadsheets/d/1aBC2defGHijklMNOpqrSTUvwxYZ/edit
                                           ^^^^^^^^^^^^^^^^^^^^^^^^
   ```
3. **Откройте доступ для сервисного аккаунта:**
   - Нажмите **"Share"** → вставьте email из `credentials.json`
   - Дайте права **"Editor"** → **"Share"**

## 🆔 Шаг 3: Получение ID рабочего чата

Чтобы отчёты дублировались в группу:

1. Добавьте `@userinfobot` в свою группу
2. Перешлите любое сообщение из группы этому боту
3. Скопируйте ID (отрицательное число, например `-1001234567890`)
4. Для супергрупп используйте полный ID с префиксом `-100`

## ⚙️ Шаг 4: Настройка конфигурации

1. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```

2. Откройте `.env` и заполните:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   REPORT_CHAT_ID=-1001234567890
   GOOGLE_SHEET_ID=id_вашей_таблицы
   GOOGLE_CREDENTIALS_FILE=credentials.json
   ALLOWED_USERS=
   NIGHT_SHIFT_START_HOUR=20
   DAY_SHIFT_START_HOUR=6
   ```

   **Описание параметров:**
   - `TELEGRAM_BOT_TOKEN` — токен из Шага 1
   - `REPORT_CHAT_ID` — ID чата для дублирования отчётов (опционально)
   - `GOOGLE_SHEET_ID` — ID таблицы из Шага 2.2
   - `ALLOWED_USERS` — ID пользователей через запятую (пусто = все)
   - `NIGHT_SHIFT_START_HOUR` — начало ночной смены (по умолчанию 20:00)
   - `DAY_SHIFT_START_HOUR` — начало дневной смены (по умолчанию 06:00)

## 🏃 Шаг 5: Запуск бота

### Вариант A: Локальный запуск

```bash
# Активируйте виртуальное окружение
source .venv/bin/activate

# Установите зависимости
pip install -r requirements.txt

# Запустите бота
python main.py
```

### Вариант B: Docker (рекомендуется)

```bash
# Сборка и запуск
docker-compose up -d --build

# Просмотр логов
docker-compose logs -f

# Остановка
docker-compose down
```

## 📱 Шаг 6: Использование бота

### Рабочий процесс

1. Откройте бота в Telegram (личные сообщения)
2. Отправьте `/start Имя ДД.ММ.ГГГГ` (или просто `/start`)
3. **Отправьте скриншот** из кассового ПО
4. Бот покажет отчёт в личке
5. Если `REPORT_CHAT_ID` настроен — отчёт дублируется в рабочий чат
6. Данные автоматически сохраняются в Google Таблицу

## 📊 Формат таблицы

Бот заполняет таблицу со следующими колонками:

| Колонка | Источник | Пример |
|---------|----------|--------|
| Дата | из команды | 28.03.2026 |
| Смена | авто-определение | День/Ночь |
| Администратор | из команды | Диана |
| Z-отчет | total | `31 905,00` |
| Игровое время + PS | game_time | `р.24 637` |
| Кальян | services | `1 800,00` |
| Бар | bar | `4 990,00` |
| Нал | cash | `2 245,00` |
| СБП+БЕЗНАЛ | sbp + cashless | `р.31 507,00` |
| СБП | sbp | `0,00` |
| Эквайринг | acquiring | `10 055,00` |
| Равно? | (оставляется пустым) | |
| ЭКВАЙРИНГ! в банк | acquiring - 2.5% | `9 803,63` |
| % экв | acquiring/total×100 | `383,50` |
| % сбп | sbp/total×100 | `113,17` |
| Расход | cash_expense | `0,00` |
| Возврат безнал | return_cashless | `0,00` |
| Возврат нал | return_cash | `0,00` |
| Инкассация | envelope | `0,00` |
| Примечание | (оставляется пустым) | |

**Форматирование чисел:**
- Разделитель тысяч: пробел (`31 905,00`)
- Десятичный разделитель: запятая
- Игровое время и СБП+БЕЗНАЛ: префикс `р.`

## 🔧 Решение проблем

### Бот не отправляет отчёты в чат

- Проверьте `REPORT_CHAT_ID` в `.env`
- Убедитесь, что бот добавлен в чат
- Для супергрупп используйте полный ID с префиксом `-100`
- Проверьте права бота в чате (администратор с правом отправки)

### Бот не запускается

**Ошибка: TELEGRAM_BOT_TOKEN not set**
- Убедитесь, что токен правильно указан в `.env`
- Проверьте, что `.env` находится в корне проекта

**Ошибка импорта модулей**
```bash
source .venv/bin/activate
pip install -r requirements.txt
```

### Ошибки Google Таблиц

**Ошибка аутентификации**
- Убедитесь, что `credentials.json` существует в папке проекта
- Проверьте, что таблица открыта для email сервисного аккаунта
- Убедитесь, что `GOOGLE_SHEET_ID` правильный

**Данные не сохраняются**
- Проверьте права сервисного аккаунта ("Editor")
- Откройте таблицу и убедитесь, что она доступна

### Проблемы с распознаванием (OCR)

**Плохое качество распознавания**
- Убедитесь, что скриншот чёткий и горизонтальный
- Бот использует EasyOCR с 4-проходной предобработкой — это покрывает большинство ошибок
- При необходимости отправьте скриншот ещё раз

### Проблемы с Docker

**Бот не стартует в контейнере**
```bash
# Проверьте логи
docker-compose logs

# Пересоберите образ
docker-compose down
docker-compose build --no-cache
docker-compose up -d
```
